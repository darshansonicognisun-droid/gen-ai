## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/gen-ai.git
cd gen-ai
```

### 2️⃣ Setup virtual environment

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```
